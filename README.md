# Выбор формы бизнеса

Учебный проект по теме «Предприятие — основное звено экономики».

## Запуск

Откройте dist/index.html в браузере двойным щелчком. Весь код находится в одном HTML-файле. Установка, сервер и интернет для расчёта не нужны. Ответы никуда не отправляются.

## Функционал и инструкция

1. Выберите деятельность, масштаб, число учредителей, инвестиции и ответственность.
2. При желании укажите капитал и совместное участие членов в деятельности.
3. Нажмите «Получить рекомендацию». Изучите основной вариант, преимущества, ограничения, альтернативы и причины исключения других форм.
4. Сохраните TXT-отчёт или распечатайте результат. Отчёт включает параметры и все альтернативы.
5. После изменения параметров повторите подбор. Кнопка «Сбросить» возвращает начальные значения.

Также есть сравнительная таблица пяти вариантов и три готовых примера.

## Критерии и алгоритм

Рассматриваются ИП, ООО, непубличное АО, ПАО и производственный кооператив.

Сначала проверяются ограничения: один владелец для ИП; максимум 50 участников для ООО; минимум 5 членов и совместное участие для кооператива. ИП и кооператив не предлагаются при желании ограничить риск вкладом. Акции требуют АО, публичное размещение — ПАО.

Затем выбирается основной вариант: ПАО для публичных акций; АО для частных акций или числа собственников свыше 50; кооператив для совместного производства при подходящих условиях; ИП для небольшого самостоятельного дела с личным риском; иначе ООО. Остальные допустимые варианты показываются как альтернативы.

Деятельность влияет на отраслевые требования и предпочтение кооперативной модели для совместного производства. Масштаб помогает оценить удобство управления, но не обязывает выбирать АО и не подтверждает статус МСП. Способ инвестирования различает кредит, долю, частные акции и публичное размещение. Ответственность учитывает готовность к личному имущественному риску.

Недостаток капитала не меняет форму автоматически: рекомендация помечается условной и показывает недостающую сумму. Общие минимумы: ООО и непубличное АО — 10 000 рублей, ПАО — 100 000 рублей. У кооператива паи определяются уставом; отсутствие универсального порога не означает отсутствие взносов.

## Границы модели

Это учебные предпочтения, а не запрет работать в другой допустимой форме. Некоторые исключения — границы модели: например, для инвестора через долю предлагается общество, хотя участие пайщиков в кооперативе возможно при отдельном анализе.

Для финансовых и специальных отраслей автоматическая форма не назначается. Для сельского хозяйства нужно дополнительно рассмотреть КФХ, сельхозкооперативы и ЕСХН. Другие формы и специальные отраслевые требования не оцениваются.

ИП — статус физического лица без создания юридического лица; ПАО — публичная разновидность АО. НПД — налоговый режим, а не ОПФ. Ограниченная ответственность имеет исключения, включая личные поручительства и субсидиарную ответственность. Налоговый режим выбирается отдельно по доходам, расходам, сотрудникам, региону и другим условиям. Таблица режимов — ориентир, а не подтверждение права их применять.
